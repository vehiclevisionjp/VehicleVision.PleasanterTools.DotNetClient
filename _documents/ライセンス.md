## 本ライブラリのライセンス

**LGPL-3.0-or-later。** `LICENSE` に LGPL の本文、`COPYING` に LGPL が参照する GPL-3.0 の本文を置いている。
`Directory.Build.props` の `PackageLicenseExpression` に SPDX 式（`LGPL-3.0-or-later`）を置き、`package.json` の `license` と `NOTICE` の SPDX 行を同じ値にしている。
本文は GitHub の licenses API（`gh api licenses/lgpl-3.0`・`licenses/gpl-3.0`）から取得した（取得日 2026-10-20）。

ライブラリなので AGPL ではなく LGPL を選んでいる。**このライブラリを使うアプリのライセンスを縛らない**（アプリ側は、LGPL の条件を守れば、AGPL・商用・その他のライセンスで配布できる）。

## 守ること

1. **Pleasanter 本体（AGPL v3）のコードを取り込まない。** コピー・流用・リンク・プロジェクト参照のいずれも不可。
   本体の著作権は自社に無く、AGPL のコードを含めると LGPL で配布できなくなる。`_reference/` は事実確認のための参照専用で、`scripts/reference-isolation-check.sh` が混ざりを検査する
2. **依存は寛容ライセンス（MIT / BSD 系 / Apache-2.0）に限る。** GPL・AGPL の依存を入れない（利用者が LGPL のまま使えなくなる）。追加時に一次情報で確認し、`NOTICE` へ追記する
3. **自社が全コードの著作権を持つ。** 外部から貢献を受けるときは、貢献者が LGPL のもとで提供することに同意していることを確認する
   （このリポジトリは CLA を求めない。デュアルライセンスにしないため）

## 後からライセンスを変えるとき

LGPL のまま公開した版は、その版の利用者に LGPL で許諾済み。以後の版を別のライセンスにする場合は、**自社が全コードの著作権を持っていること**（外部の貢献が無いか、貢献者から再許諾を受けていること）を確認してから行う。
